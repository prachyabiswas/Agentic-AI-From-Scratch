# Agentic AI Crash Course — My Notes & Practice

This repo is where I'm documenting my own notes, explanations, and hands-on code while
following the **"Agentic AI Crash Course using LangChain"** by [Codebasics](https://codebasics.io/)
(Dhaval Patel) on YouTube.

The goal: go from "what is Generative AI" all the way to building two end-to-end agentic
applications (a shopping agent and a telecom RAG chatbot), and leave behind a repo that any
beginner with basic Python knowledge can read top to bottom and actually follow along with.

> Status: work in progress. I'm building this out module by module as I go through the
> course — see [`docs/00_course_roadmap.md`](docs/00_course_roadmap.md) for what's done and
> what's coming next.
